## Precisa de uma transcrição para resumir o que foi dito em uma reunião? Não lembra o que falaram para você fazer no dia? Falaram que você não avisou algo que você lembra que na verdade avisou sim?

# Chame o VAR

VAR é um projeto que transcreve vídeos e cria um website local com os vídeos transcritos com uma barra de busca

Desta forma, você pode pesquisar por palavras chave ditas na reunião

Ao pesquisar na barra de busca, por exemplo, a palavra `atrasado`

O VAR irá mostrar que `atrasado` foi dito:
- Na reunião do dia 06/10/2024 no minuto 12:15
- Na reunião do dia 30/09/2024 no minuto 7:40
- Na reunião do dia 25/09/2024 no minuto 24:56
